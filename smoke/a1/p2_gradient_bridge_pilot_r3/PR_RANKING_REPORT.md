# P2 完整 PR、高 IoU AP 与分数排序复核

日期：2026-09-08。状态：本轮测量与500次按图像配对 bootstrap 完成；不等于机制根因已证明或 P2 最终验收通过。

## 1. 设置与可信性

使用 gradient bridge pilot r3 的 D alpha=0 / 0.1 两个原有 checkpoint，分别进行方形（rect=False）和矩形（rect=True）验证；GPU1、batch=1、imgsz=640、FP32、未融合、同一 pilot val512（3536 GT）、保留预测 conf=0.001、max_det=300。本轮没有训练，没有改动 checkpoint。

完整训练设置沿用原 pilot：train5000、5 epochs、batch4、seed260829、SGD、lr0=0.0001、lrf=0.2、momentum=0.9、weight_decay=0.0005、nbs=16、warmup_epochs=0.5、AMP=False；训练层4/6/8/23，BN及官方 C3k2 base 冻结。不是 r28 三种子的正式 P1 指标。

初次离线重算使用逆变换并裁剪的原图框，未能精确复现标准 mAP，`pr_ranking_r1` 不作为标准 AP 证据。此次重新采集验证器在输入坐标中的逐预测十档 IoU TP 标记，使用原生 `ap_per_class`，四组 mAP 复现误差均为 **0.0**。PR 曲线沿用标准全局置信度排序，包括相同分数的排序顺序。

最终证据：[pr_ranking_r3/evidence.json](pr_ranking_r3/evidence.json)；完整逐类 PR 曲线在同目录的四个 `*_curves.json`，包含 IoU=0.50:0.05:0.95、1000个 recall 采样点。原始采集：[pr_native_capture_r4/evidence.json](pr_native_capture_r4/evidence.json)。脚本记录来源 SHA256。相关 Ruff 通过，14项测试通过。

## 2. 标准 AP 结果

数值为百分比；差值为百分点（pp），矩形减方形。

| 权重 | 输入 | mAP50-95 | AP50 | AP75 | AP90 |
| --- | --- | ---: | ---: | ---: | ---: |
| D alpha=0 | 方形 | 42.4310 | 57.2830 | 46.5781 | 25.2675 |
| D alpha=0 | 矩形 | 42.3868 | 57.4917 | 46.9173 | 23.6509 |
| D alpha=0 | 差值 | -0.0442 | +0.2087 | +0.3393 | -1.6165 |
| D alpha=0.1 | 方形 | 42.5695 | 57.5833 | 46.5834 | 25.0586 |
| D alpha=0.1 | 矩形 | 42.2024 | 57.1832 | 46.2353 | 23.8599 |
| D alpha=0.1 | 差值 | -0.3671 | -0.4001 | -0.3481 | -1.1987 |

D0 并不是各阈值都退化；AP90 的损失被其他 IoU 档的收益大幅抵消。D1 在多个 IoU 档下降，AP90 差值最大。AP90 同时受定位、匹配和排序影响，不能将其下降直接等同于“定位模块是根因”。alpha=0.1 相对 alpha=0 的收益仍依赖输入形状：方形 +0.1385 pp，矩形 -0.1843 pp，尚无稳定增益证据。

## 3. 保留候选的召回与分数排序

在 conf=0.001、max_det=300 的保留候选中，按标准匹配计算的全 GT 微平均召回：

| 权重 | IoU | 方形 | 矩形 |
| --- | --- | ---: | ---: |
| D0 | 0.50 | 85.1244% | 85.1810% |
| D0 | 0.75 | 66.3744% | 66.7986% |
| D0 | 0.90 | 34.5023% | 34.0498% |
| D1 | 0.50 | 85.1810% | 85.2658% |
| D1 | 0.75 | 66.4593% | 66.9683% |
| D1 | 0.90 | 34.8699% | 34.5023% |

因此固定 conf=0.25 下的漏检，不代表低阈值候选中完全没有可用框。IoU50/75 候选召回未下降，IoU90 候选召回下降；但这里是微平均，AP 是逐类宏平均，不能直接互相抵扣，更不能称为完整网络所有候选的理论召回上限。

额外计算每类随机 TP 分数高于随机 FP 的概率（相同分数计0.5），再对两种输入均有 TP/FP 的类别等权平均：

| 权重 | IoU | 类别数 | 方形 | 矩形 |
| --- | --- | ---: | ---: | ---: |
| D0 | 0.50 | 79 | 0.94154 | 0.93521 |
| D0 | 0.75 | 79 | 0.93143 | 0.92160 |
| D0 | 0.90 | 76 | 0.94185 | 0.92418 |
| D1 | 0.50 | 79 | 0.93519 | 0.93968 |
| D1 | 0.75 | 79 | 0.92023 | 0.92365 |
| D1 | 0.90 | 77 | 0.93532 | 0.92845 |

D1 的低/中 IoU 分数区分能力并非全面变差。该指标不等同于 AP，也不是置信度校准误差；不同输入的 TP 标签和候选集合会改变，不能据此单独分解“排序贡献”。本轮不支持立即通过降低阈值或调整分类 loss 来修复全部差距。

逐类 mAP 波动很大且含极少样本类别。例如 COCO 类别索引21仅3个 GT，D0/D1 矩形差值分别为 -15.33/-26.63 pp；索引34仅8个 GT，分别 -11.97/-11.29 pp。也有明显正向变化。完整类别统计已保存在 evidence，不能将小样本大幅波动当作稳定类别规律。

## 4. val5000 配对 bootstrap

在相同5000张验证图上按图像 ID成对重采样500次，重新计算每次的全局标准 AP。百分比区间如下；CI 是验证样本不确定性，不是训练种子或总体泛化置信区间。

| 权重 | 指标 | 中位数差值（矩形−方形） | 95% CI |
| --- | --- | ---: | ---: |
| D alpha=0 | mAP50-95 | -0.1389 pp | [-0.3835, +0.0803] pp |
| D alpha=0 | AP50 | -0.1633 pp | [-0.4912, +0.1396] pp |
| D alpha=0 | AP75 | -0.0305 pp | [-0.3666, +0.2387] pp |
| D alpha=0 | AP90 | -0.4148 pp | [-0.7781, -0.0402] pp |
| D alpha=0.1 | mAP50-95 | -0.1616 pp | [-0.3889, +0.0434] pp |
| D alpha=0.1 | AP50 | -0.0822 pp | [-0.4202, +0.1890] pp |
| D alpha=0.1 | AP75 | -0.0064 pp | [-0.3224, +0.2652] pp |
| D alpha=0.1 | AP90 | -0.4621 pp | [-0.8416, -0.1269] pp |

两组 alpha 的 mAP 区间均跨0；两组 AP90 区间均完全低于0。该结果提高了“矩形输入主要影响高 IoU 质量”的可信度，但仍不能区分定位回归、匹配转换和类别分数排序的因果贡献。
