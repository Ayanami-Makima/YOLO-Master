# P2-E r2-c 结果汇总

本轮是单因素方向筛选：只将 End-to-End one-to-one 分类损失乘以 `1.2`，`1.0` 为同预算中性
对照。使用 seed 260829、pilot train5000 / val512、5 epochs、batch=4、GPU1；四组均从原始
r28 initializer 独立启动。训练和固定 val512 评估均已完成。

## 固定 val512 结果

| run | precision | recall | mAP50 | mAP50-95 |
| --- | ---: | ---: | ---: | ---: |
| B gain=1.0 | 0.622710 | 0.536556 | 0.576315 | 0.425601 |
| B gain=1.2 | 0.624659 | 0.535979 | 0.575451 | 0.424845 |
| D gain=1.0 | 0.629765 | 0.531780 | 0.575077 | 0.425896 |
| D gain=1.2 | 0.627901 | 0.535084 | 0.576686 | 0.426207 |

处理组相对同单元对照：B 的 mAP50-95 `-0.000756`，D 的 mAP50-95 `+0.000311`。D 的小幅提升
不足以证明稳定收益；B 反而轻微下降。

## 判定

该单因素改动已确认真正进入 one-to-one loss（单 batch 审计显示 gain=1.2 的分类 loss/梯度高于
gain=1.0），但单 seed、5 epoch 的结果不支持直接扩展为正式 P2 收益。应封存本轮，下一步优先
改进 one-to-one 正样本/匹配策略，或按导师意见转入另一种受控 assigner/loss 因素；不得把 D 的
`+0.000311` 写成 MoE 或分类增益的稳定优势。

旧目录 `p2_e2e_loss_r2/` 因导入错误导致处理组未生效，仅作为无效实验审计证据。
